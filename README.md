# Bharosa Bond

A responsive, sample-data prototype for a family choosing a vocational training path. The parent journey is available at `/`; the desktop-first admin demo is at `/admin`.

## Run locally

```sh
pnpm install
pnpm dev
```

Create a production build with `pnpm build`.

## Sample-data boundary

Mentor stories, names, districts, placement/pay figures, contacts, charts and escalations are demo content. Call and callback controls do not contact anyone. The WhatsApp button opens a prefilled, sample-only share link; it does not send a message. Browser speech and speech recognition depend on browser support and permissions.
